# OA / DSA Study Notes

A collection of my Data Structures & Algorithms notes, patterns, Python templates, and LeetCode solutions built while preparing for software engineering Online Assessments and technical interviews.

The goal of this repository is not just to memorize solutions, but to learn how to **recognize the underlying pattern of a problem** and understand why a solution works.

## 📚 What's Covered

The Jupyter Notebook includes problems and notes covering:

* Hash Maps & Sets
* Two Pointers
* Sliding Window
* Stacks
* Linked Lists
* Binary Search
* Trees
* Graphs & BFS/DFS
* Dynamic Programming
* Heaps / Priority Queues
* Intervals
* Backtracking
* Prefix / Suffix
* Sorting
* Python OA syntax & useful built-ins
* Time and space complexity
* Reusable algorithm templates
* Common mistakes and pattern-recognition tips

Each problem includes the general pattern, recognition clues, core idea, complexity, common traps, and a Python solution.

## 💡 Why I Made This

While preparing for OAs, I found that the biggest improvement came when I stopped thinking:

> "Have I seen this exact problem before?"

and started thinking:

> "What kind of problem is this?"

Problems such as **Linked List Cycle**, **Product of Array Except Self**, and **Race Car** especially helped me appreciate how elegant algorithmic solutions can become when you look at a problem from the right perspective.

## 🚀 How to Use It

Open:

**`OA_DSA_Study_Notes.ipynb`**

Then work through the sections alongside the corresponding LeetCode problems.

Rather than copying the solutions, I recommend trying each problem yourself first, then using the notes to understand the pattern and compare approaches.

If you're preparing for an OA or technical interview, feel free to follow the same problem set and use this notebook as a review guide.
